# To-Do List Life Dashboard

A personal, clean, and minimalist homepage dashboard designed to help users organize their daily activities efficiently. This project showcases the implementation of core frontend technologies, client-side data persistence, and interactive user interface components.

## 🚀 Features

### Core Features (MVP)
* **Dynamic Greeting & Time:** Displays the current date, real-time clock, and a contextual greeting based on the time of day (Morning/Afternoon/Evening).
* **Focus Timer:** A reliable 25-minute Pomodoro timer equipped with Start, Stop, and Reset functionalities to boost productivity.
* **Robust To-Do List:** Full CRUD capabilities (Create, Read, Update, Delete) for tasks, complete with completion toggles and persistent state tracking.
* **Quick Links:** Customized shortcut buttons to launch favorite websites instantly.
* **Local Storage Integration:** Ensures all user data (tasks and quick links) is saved directly in the browser, persisting even after page reloads.

### ⚡ Selected Challenges Implemented

* **Light / Dark Mode:** Toggle seamlessly between dark and light themes for comfortable viewing at any time of day.
* **Custom Name in Greeting:** Allows users to personalize their dashboard by entering and saving their own name.
* **Prevent Duplicate Tasks:** Validation layer that blocks users from accidentally adding identical tasks to their list.

## 🛠️ Technical Constraints & Stack

* **Structure:** HTML5
* **Styling:** Vanilla CSS3 (Responsive Design)
* **Logic:** Vanilla JavaScript (ES6+, No Frameworks)
* **Data Storage:** Browser Local Storage API (Client-side only)
* **Compatibility:** Modern web browsers (Chrome, Firefox, Edge, Safari)
